# OFM-Vaillant

Vaillant heat pumps and boilers on the KNX bus, through the **myVAILLANT cloud API**
(sensoCOMFORT VRC720 with VR921 gateway, "tli" API). Status values, operating modes,
setpoints, hot water, away mode and daily energy figures.

Modelled on [myPyllant](https://github.com/signalkraft/myPyllant) /
[mypyllant-component](https://github.com/signalkraft/mypyllant-component) for Home Assistant.
The API is not officially documented; Vaillant may change it at any time.

## Requirements

- myVAILLANT account (e-mail and password of the app) with a registered system
- Internet access from the KNX device
- ESP32 with PSRAM only. The login needs an ALTCHA proof of work (PBKDF2-SHA256) and TLS
  to the Vaillant cloud, which needs hardware SHA and PSRAM for the TLS buffers.
